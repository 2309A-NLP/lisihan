## 二、架构说明

```
用户输入 → Agent引擎(LLM决策)
               │
               ▼ MCP list_tools() → 动态发现5个工具
               │
               ▼ LLM 决定调哪个工具
               │
               ▼ MCP call_tool(name, args)
               │
               ▼ 对应后端API (HTTP)
               │
               ▼ 结果返回 → 自然语言回复
```

## 三、开发步骤

### Phase 1: MCP 工具服务器 ✅ `mcp_server.py`
5 个工具，每个通过 HTTP 调用对应后端服务，通过 `@mcp.tool()` 注册。

### Phase 2: Agent 核心引擎 ✅ `core/agent.py`
- MCP Client：连接 MCP 服务器、发现工具、调用工具
- LLM Prompt：意图识别 + 工具选择决策
- 多轮对话历史管理

### Phase 3: Web 界面 ✅ `frontend/web_app.py`
Flask Web 应用 + 建议快捷按钮

### Phase 4: 配置与脚本 ✅
- `config/config.yaml` — LLM API Key + 工具地址
- `启动所有服务.bat` — 一键启动
- `启动CLI模式.bat` — 命令行测试
