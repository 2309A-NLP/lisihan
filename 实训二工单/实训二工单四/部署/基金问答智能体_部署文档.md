## 一、项目概览

| 项目 | 详情 |
|------|------|
| 类型 | 基金数据问答智能体（博金杯金融挑战赛） |
| 核心功能 | 用户问基金/股票问题 → AI 自动生成 SQL → 查询 1.46GB 金融数据库 → 给出答案 |
| 工作模式 | ReAct Agent（LLM 自主决策）+ 备用正则解析器双模式 |

| 运行平台 | **Windows** |

## 二、前置依赖

### 2.1 确认 Conda 环境

项目根目录已有 Bat 脚本自动检测 Python 路径，但建议使用已激活的 `py310` 环境：

```bash
conda activate py310
python --version   # 应是 Python 3.10.x
```

### 2.2 安装 Python 依赖

双击 `启动智能体.bat` 会自动检测并安装缺少的依赖，也可手动安装：

```bash
cd C:\Users\freedom\Desktop\agent\基金问答智能体
pip install flask requests
```

> 只需要这两个依赖 — `flask` 提供 Web 服务，`requests` 调用 SiliconFlow API。

### 2.3 获取 SiliconFlow API Key（必需）

本项目使用 SiliconFlow 的 DeepSeek-V3 API 进行 SQL 生成和推理。

**申请步骤**：

1. 访问 https://siliconflow.cn（可能需要注册账号）
2. 进入 API Keys 页面创建 Key
3. 充值获取调用额度

**配置方式**：

编辑 `code/react_agent.py` 第 32 行：
```python
API_KEY = "你的API密钥"
```

> ⚠️ **注意**：当前代码中包含测试用的回退 API Key。**部署前务必替换为你自己的 Key**，避免额度共享或泄露。

## 四、使用说明

### 4.1 Web 界面

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 浏览器访问 `http://localhost:5002` | 深色主题界面 |
| 2 | 输入框输入问题 | 支持自然语言 |
| 3 | 点击"发送"或按 Enter | 等待 LLM 生成 SQL + 查询 |
| 4 | 查看答案 | 结果以中文显示 |

**示例问题**：

```
📌 股票行情统计类
  20210415日，建筑材料一级行业涨幅超过5%（不包含）的股票数量
  20210105日，中信行业分类的综合金融行业中，涨跌幅最大股票的股票代码和涨跌幅
  20210304日，一级行业为非银金融的股票的成交量合计是多少？

📌 基金信息查询类
  嘉实基金管理有限公司2019年成立了多少基金？
  基金代码为000001的基金管理人是谁？

📌 涨跌幅计算类
  在2021年度，688338股票涨停天数？（涨停定义：收盘价/昨收盘-1 >= 9.8%）
  20210415日申万行业分类的建筑材料一级行业涨幅超过5%的股票
```

### 4.2 批量测试（大赛提交）

准备投递比赛结果时使用：

```bash
双击 批量测试.bat
```

或命令行：
```bash
python code\batch_test.py
```

**特性**：
- 从 `question_db.json`（603 道赛题）逐题处理
- **每 50 题自动保存一次结果**
- **支持断点续跑** — 中断后重新运行自动跳过已完成的题目
- 两段式工作流：生成 SQL → 执行 → 生成答案
- SQL 失败自动重试（最多 2 次降级）
- 结果行数 > 500 自动重试

**生成提交文件**：
```bash
python code\make_submit.py
```
输出：`output/submission.jsonl`（纯净提交格式）

## 五、系统架构

```
用户浏览器 (localhost:5002)
         │
         ▼
┌─────────────────────────────────────────┐
│         Flask Web App (app.py)          │
│                                         │
│  POST /ask → answer_question(question)  │
└─────────────────┬───────────────────────┘
                  │
        ┌─────────┴─────────┐
        ▼                   ▼
┌─────────────────┐  ┌─────────────────┐
│  策略1          │  │  策略2          │
│  ReAct Agent    │  │  备用解析器      │
│  (LLM 生成 SQL) │  │  (正则匹配)      │
│                 │  │                 │
│  ├─ SYSTEM→     │  │  ├─ 提取日期    │
│  │  Thought→    │  │  ├─ 提取行业    │
│  │  Action→     │  │  ├─ 提取涨幅    │
│  │  query_db    │  │  └─ 数据库查询  │
│  └─ FinalAnswer │  └─ 返回答案      │
└────────┬────────┘  └────────────────┘
         │
         ▼
┌─────────────────────────────────────────┐
│        SQLite 金融数据库 (1.46GB)        │
│                                         │
│  博金杯比赛数据.db - 10 张表             │
│                                         │
│  ① 基金基本信息         ⑥ A股票日行情表   │
│  ② 基金股票持仓明细     ⑦ 港股票日行情表   │
│  ③ 基金债券持仓明细     ⑧ A股公司行业划分  │
│  ④ 基金可转债持仓明细   ⑨ 基金规模变动表   │
│  ⑤ 基金日行情表        ⑩ 基金份额持有人结构 │
└─────────────────────────────────────────┘
```

**数据流示例**（"20210415日建筑材料行业涨幅超5%的股票数量"）：

```
1. 用户输入 → POST /ask → answer_question()
2. ReAct Agent 收到问题
3. LLM 生成 SQL：
   WITH ind AS (
     SELECT DISTINCT 股票代码 FROM "A股公司行业划分表"
     WHERE 一级行业名称='建筑材料' AND 交易日期<='20210415'
   )
   SELECT COUNT(*) FROM "A股票日行情表" s
   JOIN ind ON s.股票代码=ind.股票代码
   WHERE s.交易日='20210415'
     AND (s."收盘价(元)"-s."昨收盘(元)")/s."昨收盘(元)"*100 > 5
4. 执行 SQL → 得到数字
5. LLM 生成答案 → "2021年4月15日，建筑材料一级行业涨幅超过5%的股票数量为 XX 只。"
6. 返回 JSON 给浏览器
```

## 八、常见问题排查

### Q1：启动时提示数据库不存在

```
[WARN] 数据库未找到: ...\博金杯比赛数据.db
```

→ 需要下载数据集：
```bash
git lfs install
git clone https://www.modelscope.cn/datasets/BJQW14B/bs_challenge_financial_14b_dataset.git
```
然后将 `dataset/博金杯比赛数据.db` 放到 `bs_challenge_financial_14b_dataset/dataset/` 下。

### Q2：AI 回答"【LLM调用失败】"

→ 检查：API Key 配置是否正确？网络是否连通？
→ 系统会自动降级到备用解析器（正则匹配），但只能处理简单格式的问题

### Q3：API 返回 401/403

→ API Key 无效或已过期，请在 SiliconFlow 控制台重新生成

### Q4：SQL 查询结果为空

→ 可能原因：日期不在 2019-2021 范围内、行业名称不匹配、数据集中确实无记录
→ ReAct Agent 会自动重试或调整 SQL

### Q5：批量测试太慢

→ 每个问题需要调用 2-3 次 LLM（生成 SQL→执行→生成答案），603 题可能需要数小时
→ 脚本支持断点续跑，中断后重跑自动跳过已完成题目

### Q6：控制台出现乱码

→ 解决方案：启动前执行 `set PYTHONIOENCODING=utf-8`
→ `react_agent.py` 第 22-25 行已自动修复 Windows 编码

### Q7：Flask 启动失败（端口被占用）

→ 修改 `app.py` 第 350 行的 `port` 变量值为其他端口（如 5003）
