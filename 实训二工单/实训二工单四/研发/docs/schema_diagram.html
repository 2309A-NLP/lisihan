基金问答智能体 - 架构图

ReAct Agent · DeepSeek-V3 · 589道基金问题

ReAct 流程

  • User → 输入问题
  • Think → Agent 分析需要什么信息
  • Act → 调用 query_db 工具
  • Observe → 获取SQL结果
  • Loop → 继续思考/给出最终答案

数据库（10张表）

  • 基金基本信息（代码/名称/类型/规模）
  • 基金股票/债券/可转债持仓明细
  • A股日行情 + 港股日行情
  • 基金日行情（单位净值）
  • A股公司行业划分（中信/申万）
  • 基金规模变动 + 持有人结构

技术栈

  • LLM: DeepSeek-V3 (SiliconFlow API)
  • 框架: 自研 ReAct Agent
  • 前端: Flask + HTML/CSS/JS
  • 数据库: SQLite 1.5GB
  • 批处理: 589题断点续跑
