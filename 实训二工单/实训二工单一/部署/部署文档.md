## 2. 快速部署（一键启动）

### 2.1 安装 Python 依赖

```bash
cd family_accounting_agent
pip install -r requirements.txt
```

`requirements.txt` 内容：

```
flask>=2.0.0
pymysql>=1.0.0
```

### 2.2 确保 MySQL 运行中

```bash
# 检查 MySQL 状态
systemctl status mysql
# 或
mysqladmin ping -u root -p

# 如未安装 MySQL，安装方式（Ubuntu/Debian）：
sudo apt update
sudo apt install mysql-server -y
sudo systemctl start mysql
```

### 2.3 启动应用

```bash
cd family_accounting_agent
python app.py
```

或通过 `main.py` 入口启动：

```bash
python main.py
```

启动后访问：**http://localhost:8080**

## 3. MySQL 数据库配置

### 3.1 环境变量控制（推荐）

应用通过环境变量读取 MySQL 连接信息，不需要修改代码：

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| `MYSQL_HOST` | `127.0.0.1` | 数据库地址 |
| `MYSQL_PORT` | `3306` | 数据库端口 |
| `MYSQL_USER` | `root` | 数据库用户名 |
| `MYSQL_PASSWORD` | `root` | 数据库密码 |
| `MYSQL_DATABASE` | `family_accounting` | 数据库名（自动创建） |

**Windows CMD 设置：**

```cmd
set MYSQL_HOST=127.0.0.1
set MYSQL_USER=root
set MYSQL_PASSWORD=your_password
set MYSQL_DATABASE=family_accounting
python app.py
```

**Windows PowerShell 设置：**

```powershell
$env:MYSQL_HOST="127.0.0.1"
$env:MYSQL_USER="root"
$env:MYSQL_PASSWORD="your_password"
$env:MYSQL_DATABASE="family_accounting"
python app.py
```

**Linux/macOS 设置：**

```bash
export MYSQL_HOST=127.0.0.1
export MYSQL_USER=root
export MYSQL_PASSWORD=your_password
export MYSQL_DATABASE=family_accounting
python app.py
```

### 3.2 不设环境变量（使用默认值）

默认连接参数：

| 参数 | 默认值 |
|------|--------|
| 地址 | `127.0.0.1` |
| 端口 | `3306` |
| 用户 | `root` |
| 密码 | `root` |
| 数据库 | `family_accounting` |

> ⚠️ 如果你的 MySQL root 密码不是 `root`，必须设置 `MYSQL_PASSWORD` 环境变量，否则启动会报错。

### 3.3 初始化逻辑（自动）

应用启动时自动完成以下操作（无需手动导入 SQL）：

1. 创建数据库 `family_accounting`（如不存在）
2. 创建表 `money_notes`（记账主表）
3. 创建表 `budget_config`（预算配置表）

### 3.4 手动建表（备用）

如需要手动创建，SQL 如下：

```sql
CREATE DATABASE IF NOT EXISTS family_accounting
  DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

USE family_accounting;

CREATE TABLE IF NOT EXISTS money_notes (
    id INT PRIMARY KEY AUTO_INCREMENT,
    date DATE NOT NULL,
    member VARCHAR(50) NOT NULL,
    item VARCHAR(200) NOT NULL,
    amount DECIMAL(10,2) NOT NULL,
    type ENUM('收入','支出') NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS budget_config (
    id INT PRIMARY KEY AUTO_INCREMENT,
    month VARCHAR(7) NOT NULL UNIQUE,
    budget_amount DECIMAL(10,2) NOT NULL,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

## 4. 应用配置说明

### 4.1 项目结构

```
family_accounting_agent/
├── app.py              # Flask Web 应用（API + 路由）
├── main.py             # 入口文件（可直接用 app.py）
├── agent.py            # 智能体对话逻辑
├── db.py               # 数据库 CRUD 操作
├── nlp.py              # 自然语言解析器
├── add_flow.py         # 记账流程
├── query_flow.py       # 查询流程
├── mutation_flow.py    # 删改流程
├── budget_flow.py      # 预算管理流程
├── formatters.py       # 响应格式化
├── constants.py        # 常量（开场白、成员别名等）
├── requirements.txt    # Python 依赖
├── templates/
│   └── index.html      # 前端聊天页面
└── static/
    ├── style.css       # 样式
    ├── app.css         # （备用样式）
    └── app.js          # （备用脚本）
```

### 4.2 启动参数

应用默认监听 `127.0.0.1:8080`，debug 模式。如需修改：

**修改 port：** 编辑 `app.py` 最后一行

```python
app.run(host="127.0.0.1", port=8080, debug=True)
```

**允许外部访问：**

```python
app.run(host="0.0.0.0", port=8080, debug=False)
```

> ⚠️ 生产环境建议关闭 `debug=True`，否则错误信息会暴露给用户。


## 7. 生产环境部署

### 7.1 使用 Gunicorn（Linux 推荐）

```bash
pip install gunicorn

# 启动（4 workers）
gunicorn -w 4 -b 0.0.0.0:8080 app:create_app()
```

### 7.2 使用 Waitress（Windows 推荐）

```bash
pip install waitress

waitress-serve --host=0.0.0.0 --port=8080 app:create_app
```

### 7.3 Nginx 反向代理（可选）

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### 7.4 systemd 服务（Linux）

创建 `/etc/systemd/system/family-accounting.service`：

```ini
[Unit]
Description=Family Accounting Agent
After=network.target mysql.service

[Service]
Type=simple
User=your-user
WorkingDirectory=/path/to/family_accounting_agent
Environment=MYSQL_PASSWORD=your_password
ExecStart=/usr/bin/python /path/to/family_accounting_agent/app.py
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

启用：

```bash
sudo systemctl daemon-reload
sudo systemctl enable family-accounting
sudo systemctl start family-accounting
```

## 8. 常见问题

### Q1：启动报错 `ModuleNotFoundError: No module named 'pymysql'`

**原因：** 未安装 PyMySQL

**解决：**

```bash
pip install -r requirements.txt
```

### Q2：启动报错 `Can't connect to MySQL server`

**原因：** MySQL 未运行或连接参数不对

**排查步骤：**

1. 确认 MySQL 是否运行：`systemctl status mysql` 或 `mysqladmin ping`
2. 确认连接参数正确：检查 `MYSQL_HOST`、`MYSQL_PORT`、`MYSQL_USER`、`MYSQL_PASSWORD` 环境变量
3. 确认密码正确：`mysql -u root -p` 手动登录测试

### Q3：页面显示但聊天无响应

**排查：**

1. 检查 Flask 是否打印了请求日志（终端输出）
2. 浏览器打开 F12 → Console 查看是否有网络错误
3. 直接 curl 测试 `/api/chat` 接口

### Q4：数据库连接报 `Authentication plugin 'caching_sha2_password'`

**原因：** MySQL 8.0+ 默认认证插件不兼容

**解决：**

```sql
ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY '你的密码';
FLUSH PRIVILEGES;
```

### Q5：Windows 上端口被占用

```cmd
# 查看 8080 端口占用
netstat -aon | findstr :8080

# 杀掉占用进程
taskkill /PID <进程ID> /F
```

|------|------|------|
| GET | `/` | 主页（聊天界面） |
