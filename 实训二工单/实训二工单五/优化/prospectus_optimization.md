## 4 Chunk策略优化方案 (推荐最先实施)

### 4.1 当前方案

```
固定400字符分块 + 80字符重叠
- 优点：简单、可预测
- 缺点：可能切断语句/段落、丢失上下文
```

### 4.2 推荐方案

```
语义分块 (recursive character text splitter):
1. 先用句号/分号/换行符分割
2. 合并至接近目标大小
3. 保留完整句子
4. 按段落边界回退切分

参数建议:
- chunk_size: 300-500字符
- chunk_overlap: 50-100字符
- separators: ["\n\n", "\n", "。", "；", "，", " "]
- 按文档标题/章节首句保留元信息
```

## 5 混合检索实现方案

```python
# BM25 + FAISS 加权融合伪代码
def hybrid_search(query, faiss_index, bm25, chunks, alpha=0.5):
    # FAISS向量检索
    vec_scores, vec_indices = faiss_index.search(query_emb, top_k*2)
    
    # BM25关键词检索
    bm25_scores = bm25.get_scores(query.split())
    bm25_top = np.argsort(bm25_scores)[::-1][:top_k*2]
    
    # RRF (Reciprocal Rank Fusion) 融合
    all_indices = set(vec_indices[0]) | set(bm25_top)
    final_scores = {}
    for idx in all_indices:
        rank_vec = rank_in_list(idx, vec_indices[0])
        rank_bm25 = rank_in_list(idx, bm25_top)
        final_scores[idx] = alpha/(60+rank_vec) + (1-alpha)/(60+rank_bm25)
    
    return sorted(final_scores.items(), key=lambda x: -x[1])[:top_k]
```
