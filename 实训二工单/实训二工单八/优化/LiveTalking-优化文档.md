## 1. 概述

LiveTalking 是一个基于 AI 的数字人实时对话系统，集成了语音识别（ASR）、大语言模型（LLM）、语音合成（TTS）和数字人驱动（Avatar）等模块。系统支持多会话并发、WebRTC 实时音视频通信，能够实现端到端的 AI 数字人对话体验。

本文档记录了项目从初始版本到当前版本之间的所有已实施优化，以及已识别但尚未实施的待优化项，供开发和维护团队参考。

  - 新增 `benchmark_asr.py` ASR 性能基准测试工具，支持准确率和速度评估
  - 支持自动 fallback 策略：`asr_server=local` 使用本地推理，或配置 `http://xxx` 使用远程服务
  - 可配置项：`asr_device`（cuda:0 / cpu）、`asr_language`（zh / en）
- **涉及文件**：
  - `server/asr_server.py` — 新增，本地 ASR 推理服务

## 3. 待做的优化

### 3.1 日志轮转（Log Rotation）

| 项目 | 内容 |
|------|------|
| **问题描述** | 当前 `livetalking.log` 持续写入同一文件，随运行时间增长文件体积无限增大，可能导致磁盘空间耗尽。 |
| **建议方案** | 使用 Python `logging.handlers.RotatingFileHandler` 或 `TimedRotatingFileHandler` 实现自动轮转。建议配置：最大文件大小 10MB，保留 5 个备份文件。 |
| **优先级** | 🔴 **高** — 生产环境必备，长期运行系统需立即处理 |

**示例代码片段**：

```python
import logging
from logging.handlers import RotatingFileHandler

handler = RotatingFileHandler(
    'livetalking.log', maxBytes=10*1024*1024, backupCount=5
)
logging.getLogger().addHandler(handler)
```
