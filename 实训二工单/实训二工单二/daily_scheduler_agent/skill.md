# 日程提醒智能体 Skill

## Agent 信息

名称：日程提醒智能体。版本：1.0.0。描述：基于自然语言的日程管理助手，支持增删改查、循环提醒、智能引导。

## 核心技能

### 添加日程

触发词：添加、提醒我、帮我记、记住。

参数：提醒时间、日程内容、循环规则（可选）。

示例：提醒我明天下午5点开会。

### 查询日程

触发词：查看、有什么日程、今天的安排、现在有什么。

参数：查询范围，如今天、明天、全部、最近。

示例：我今天有什么日程。

### 删除日程

触发词：删除、取消、移除。

参数：日程编号或日程内容。删除操作需要二次确认。

示例：删除日程1。

### 修改日程

触发词：修改、改、调整。

参数：日程编号、新时间、新内容、循环规则（可选）。

示例：修改日程1为明天下午3点开会。

### 循环日程

触发词：每天、每周、每月、工作日。

参数：循环规则、提醒时间、日程内容、结束日期（可选）。

示例：每天上午8点起床。

## 对话流程

场景一：缺少时间时，用户说“提醒我买咖啡”，智能体反问“请告诉我提醒时间”。

场景二：缺少内容时，用户说“下午5点”，智能体反问“请告诉我下午5点要做什么”。

场景三：删除确认时，用户说“删除日程1”，智能体要求回复“确认删除”。

## 输出格式

添加成功输出带编号的日程。查询结果输出日程列表。删除成功输出“已删除”。循环日程输出“每天重复”。

## 技术信息

数据存储：MySQL。提醒方式：系统弹窗加日志文件。运行模式：Web界面加后台守护进程。自然语言处理：正则表达式加关键词匹配。

## 使用方式

Web界面：双击 start_web.bat。命令行：输入 python interactive.py。后台服务：输入 manage.sh start。

## 版本历史

1.0.0 版本包含增删改查、循环日程、Web界面、后台提醒。
