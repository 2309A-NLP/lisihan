| 表名 | 说明 | 关键字段 |
|------|------|----------|

验证 SQL：
```sql

SELECT * FROM agent_execution_logs ORDER BY execution_time DESC LIMIT 10;
```

## 五、架构说明

```
┌─────────────────────────────────────────────────┐
│              用户浏览器 (localhost:5000)            │
├─────────────────────────────────────────────────┤
│     Flask Web App (web_app.py)                  │
│     ├─ /chat         → 自然语言日程管理             │
│     ├─ /today        → 今日日程查询                │
│     ├─ /reminders    → 提醒轮询接口                │
│     └─ /test_notification → Toast 弹窗测试        │
├─────────────────────────────────────────────────┤
│     SchedulerAgent (核心业务逻辑)                   │
│     ├─ IntentParser    → 自然语言 → 意图解析         │
│     ├─ InputValidator  → 参数校验 / 补全引导        │
│     └─ ScheduleDAO     → 数据库 CRUD               │
├─────────────────────────────────────────────────┤
│     MySQL (schedule_db)                          │
│     ├─ schedules                                 │
│     ├─ agent_execution_logs                      │
│     └─ reminder_logs                             │
└─────────────────────────────────────────────────┘
          ↓ (Windows Toast)
     PowerShell NotifyIcon → 右下角弹窗
```

### 数据流（以"提醒我明天下午5点开会"为例）

1. **用户输入** → `POST /chat` → `SchedulerAgent.process()`
2. **意图解析** → `IntentParser.parse()` → 识别意图 `add`，提取时间 `明天17:00`、内容 `开会`
3. **参数校验** → `InputValidator.validate_add_payload()` → 参数完整，通过
4. **写入数据库** → `ScheduleDAO.add_schedule()` → 写入 MySQL `schedules` 表
5. **返回结果** → `"好的，已添加日程：明天 17:00 开会（编号 #1）"`
6. **到期提醒** → 前端轮询 `/reminders` → 查到到期日程 → 发 Toast 弹窗

## 六、常见问题排查

### Q1: MySQL 连接失败
```
处理失败：(2003, "Can't connect to MySQL server on '127.0.0.1:3306'")
```
→ 检查：MySQL 服务是否启动、端口是否正确、密码是否匹配

### Q2: Toast 弹窗不显示
→ Windows 通知中心可能已关闭应用的通知权限。检查：
`设置 → 系统 → 通知和操作`，确保"获取来自应用和其他发送者的通知"已开启

### Q3: start_web.bat 闪退
→ 右键以管理员身份运行，或在 cmd 中手动执行查看错误输出
