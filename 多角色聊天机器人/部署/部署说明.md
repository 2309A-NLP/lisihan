# 多角色聊天机器人 - 部署说明

## 📋 项目概述
基于 FastAPI + RAG 的多角色聊天机器人系统，支持医生、律师、心理医生、股票分析师等多种角色智能对话。

## 🖥️ 环境要求

| 组件 | 版本要求 | 用途 |
|------|---------|------|
| Python | 3.8+ | 运行环境 |
| MySQL | 5.7+ | 数据持久化 |
| Redis | 6.x+ | 短期记忆缓存 |
| Milvus | 2.x+ | 向量知识库 |

## 🚀 快速部署

### 方式一：一键部署（推荐）
双击运行 `deploy.bat`，脚本会自动完成：
1. 检查 Python 环境
2. 创建虚拟环境
3. 安装依赖（自动使用清华镜像）
4. 检查数据库服务
5. 启动应用

### 方式二：手动部署

#### 1. 安装依赖
```bash
cd 多角色聊天机器人
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

#### 2. 配置数据库
编辑 `config/mysql_config.py`，填写 MySQL 连接信息：
```python
MYSQL_HOST = "localhost"    # MySQL 服务器地址
MYSQL_PORT = 3306           # MySQL 端口
MYSQL_USER = "root"         # MySQL 用户名
MYSQL_PASSWORD = "****"     # MySQL 密码
MYSQL_DATABASE = "chatbot"  # 数据库名
```

#### 3. 启动服务
```bash
.venv\Scripts\python -m uvicorn main:app --reload --port 8080
```

## ❓ 常见问题

**Q: pip 安装失败？**
使用清华镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

**Q: Milvus 连接不上？**
确保 Milvus 已启动，或修改 `.env` 中的 `MILVUS_HOST` 地址

**Q: 数据库初始化失败？**
1. 确保 MySQL 服务已启动
2. 检查 `config/mysql_config.py` 中的连接信息
3. 手动创建数据库：`CREATE DATABASE chatbot CHARACTER SET utf8mb4;`

**Q: 启动后页面空白？**
打开浏览器开发者工具（F12），查看 Console 是否有报错信息
