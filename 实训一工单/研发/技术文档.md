# PDF 招股说明书智能问答系统技术文档

工单编号：人工智能 NLP-RAG-基于 PDF 文档的问答系统

## 1. 项目概述

本项目用于对招股说明书 PDF 构建本地 RAG 问答系统，支持正文、表格、固定元数据、工单问题评估和 Streamlit 页面交互。

当前核心能力：

- PDF 正文解析：优先使用 MinerU WSL，失败后回退 PyMuPDF。
- 表格解析：使用 pdfplumber 抽取表格，并转换为 Markdown 文本进入检索。
- 多策略切块：段落/句子切块、标题切块、父子块切块、递归切块。
- 固定字段直答：公司名称、法定代表人、注册资本、成立日期、注册地址。
- 混合检索：BM25 + Milvus 向量检索 + RRF 融合。
- 记忆能力：Redis 短期对话记录，Milvus 长期优质问答记忆。
- 评估能力：内置工单问题批量测试并输出 JSON 结果。

## 2. 运行链路

```text
data/*.pdf
  -> MinerU WSL 或 PyMuPDF/pdfplumber
  -> pdf_parser 解析、清洗、切块
  -> parsed_pdfs/*_chunks.json + *_metadata.json
  -> RAGEngine 初始化知识库
  -> HybridRetriever 构建 BM25，并按需调用 Milvus 向量检索
  -> 元数据直答 / 规则抽取 / LLM 生成
  -> Streamlit 页面或命令行输出
```

解析结果会记录 `chunk_strategy`、`chunk_size`、`chunk_overlap`。当切块参数变化时，`PDFParser` 会忽略旧缓存并重新解析，避免旧切块结果被误用。

## 4. PDF 解析与切块

入口位于 `pdf_parser/main.py`。

默认解析策略：

1. 如果 `ENABLE_MINERU_WSL=true`，先尝试使用 WSL 中的 MinerU。
2. MinerU 成功后调用 `mineru_output_to_parsed_result` 转成统一 chunks JSON。
3. MinerU 失败时回退 PyMuPDF 正文抽取和 pdfplumber 表格抽取。
4. 文本和表格进入 `merge_blocks`，再按配置选择切块策略。

支持的切块策略：

| 策略 | 配置值 | 说明 |
| --- | --- | --- |
| 段落/句子切块 | `paragraph` | 默认策略，合并相邻文本块后按句子切分超长段落 |
| 标题切块 | `title` | 识别 Markdown 标题、章节号、中文序号标题，按章节组织上下文 |
| 父子块切块 | `parent_child` | 生成父块上下文和子块片段，子块带 `parent_id`、`heading_path` 等元数据 |
| 递归切块 | `recursive` | 按段落、换行、句末标点、空格逐级拆分，并支持 overlap |

相关配置位于 `src/config.py`：

```python
PDF_CHUNK_STRATEGY = "paragraph"
PDF_CHUNK_SIZE = 500
PDF_CHUNK_OVERLAP = 50
```

也可在 Streamlit 侧边栏选择切块方式、切块大小和重叠字符数，然后点击“按当前切块方式重新解析并构建索引”。

## 5. 检索与回答

入口位于 `src/rag_engine.py`。

回答优先级：

1. 否定类问题预处理。
2. 固定元数据直答。
3. 特定表格和实体规则抽取。
4. 长期记忆命中。
5. 混合检索上下文 + 规则抽取。
6. LLM 基于上下文生成。
7. 质量校验失败时重试检索或返回无法验证提示。

检索模块位于 `src/retriever.py`：

- BM25 是主召回方式。
- Milvus 用于向量召回。
- RRF 融合 BM25 和向量召回。
- 精确问题可跳过向量召回，降低响应时间。

## 6. 记忆与评估

短期记忆：

- Redis 保存最近对话。
- 页面只展示最近记录，不直接参与 PDF 检索答案生成。

长期记忆：

- Milvus 保存用户标记“有帮助”的优质问答。
- 精确数值、比例、实体问题会跳过长期记忆，避免答案被旧记忆污染。

评估：

- 页面按钮“运行工单问题评估”用于交互式评估。
- `test_工单问题.py` 用于生成 `工单问题测试结果.json`。

## 7. 配置

主要配置位于 `src/config.py`。

常用环境变量：

```powershell
$env:PDF_DIR="./data"
$env:PDF_PARSE_OUTPUT_DIR="./parsed_pdfs"
$env:PDF_CHUNK_STRATEGY="paragraph"
$env:PDF_CHUNK_SIZE="500"
$env:PDF_CHUNK_OVERLAP="50"

$env:ENABLE_MINERU_WSL="true"
$env:MINERU_OUTPUT_DIR="./mineru_output"

```

## 10. 排查建议

- 知识库初始化失败：检查 `data/` 是否有 PDF，查看 `logs/app.log`。
- MinerU 失败：检查 WSL、conda 环境和 `docs/mineru_wsl_usage.md`，系统会自动回退 PyMuPDF。
- 回答跑偏：展开页面“查看检索片段”，确认命中的 chunk 是否正确。
- 固定字段错误：检查 `parsed_pdfs/*_metadata.json` 和 `pdf_parser/metadata_extractor.py`。
- 切块结果不符合预期：检查 `parsed_pdfs/*_chunks.json` 中的 `chunk_strategy`、`heading_path`、`parent_id` 等字段。
