## 模块命名规律

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| **M - Model** | `src/models.py` | 数据模型定义 |
| **V - View** | `app.py` | Streamlit 界面 |
| **C - Controller** | `src/rag_engine/` | 业务逻辑编排 |
| **P - Parser** | `pdf_parser/` | PDF 文档解析 |
| **R - Retriever** | `src/retriever/` | 多策略检索 |
| **G - Graph** | `src/graph_rag/` | 知识图谱 |
| **L - LLM** | `utils/llm_engine/` | LLM 交互封装 |
| **M - Memory** | `src/memory_manager.py` | 长短期记忆 |
| **E - Evaluation** | `utils/evaluator.py` | RAG 效果评估 |
