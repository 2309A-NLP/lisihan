## MinerU Batch Parsing

- Default PDF parser backend is `mineru`, and the output directory is `mineru_output`.
- MinerU raw files must be kept: `mineru_output/<pdf-stem>/auto/<pdf-stem>.md` and `mineru_output/<pdf-stem>/auto/<pdf-stem>_content_list.json`.
- The project adapter still writes `mineru_output/<pdf-stem>_chunks.json`, so the RAG, retrieval, and QA pipeline can keep using the original chunk JSON shape.
- Parse every PDF in `data`:

```powershell
.\.venv\Scripts\python.exe run_mineru_wsl.py data --output-dir mineru_output
```

- Parse any number of explicit PDF files:

```powershell
.\.venv\Scripts\python.exe run_mineru_wsl.py data\鎷涜偂璇存槑涔?.pdf data\鎷涜偂璇存槑涔?.pdf data\鍏跺畠鏂囦欢.pdf --output-dir mineru_output
```

- `python -m pdf_parser.cli` also accepts directories or multiple PDF files, and prints chunk count, table count, image count, page count, parser backend, MinerU markdown path, and MinerU content-list path.
