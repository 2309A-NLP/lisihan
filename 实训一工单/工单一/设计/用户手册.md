# PDF文档问答系统用户手册

工单编号：人工智能NLP-RAG-基于PDF文档的问答系统

## 1. 功能简介

本系统用于基于 PDF 文档内容进行智能问答，当前只使用 BM25 关键词检索，不保存短期记忆或长期记忆。

支持：

- PDF 文档知识库构建
- 网页聊天问答
- 命令行评测演示
- 问答反馈记录

## 2. 使用前准备

1. 准备 Python 运行环境
2. 安装项目依赖
3. 将需要问答的 PDF 文件放入 `data/` 目录

## 3. 启动方式

### 3.1 Web 页面

执行：

```bash
python main.py
```

启动后，浏览器会打开 Streamlit 页面。

### 3.2 命令行模式

执行：

```bash
python main.py --mode cli
```

该模式用于批量评测与调试。

## 4. 页面操作指南

### 4.1 左侧配置面板

页面左侧显示当前系统状态，包括：

- 检索方式
- 索引名称
- 召回条数

可在此执行：

- 重新解析 PDF 并构建 BM25 索引
- 运行工单问题评估

### 4.2 问答输入

在页面下方输入问题后，系统会自动：

1. 分类问题类型
2. 检索相关文档片段
3. 生成回答

### 4.3 查看检索片段

回答生成后，可展开查看系统检索到的上下文片段和得分。

### 4.4 反馈按钮

回答下方提供两个反馈按钮：

- 有帮助
- 需改进

反馈仅用于记录当前交互，不会写入长期记忆。

## 5. 历史记录

当前版本不提供短期历史和长期记忆查看。

## 6. 常见问题

### 6.1 页面提示知识库未初始化

请确认：

- `data/` 中存在 PDF 文件
- 已重新解析并构建索引

### 6.2 回答质量一般

可尝试：

- 换更明确的问题表达
- 确认 PDF 内容本身是否清晰
- 调整问题中的关键词

## 7. 评估功能

点击“运行工单问题评估”后，系统会对内置问题集进行批量测试，并输出：

- 平均响应时间
- 成功率
- RAG 与纯 LLM 的对比结果
- 每个问题的 PDF 答案、纯 LLM 答案和对比评分

## 8. 文件说明

- `main.py`：程序入口
- `app.py`：网页应用入口
- `data/`：PDF 文档目录
- `logs/`：运行日志目录
