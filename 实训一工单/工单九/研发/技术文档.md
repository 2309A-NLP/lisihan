# PDF 金融文档智能问答系统技术文档

工单编号：人工智能 NLP-RAG-Graph RAG 优化任务

## 1. 项目概述

本项目面向招股说明书、年度报告等金融 PDF 文档，构建基于 Hybrid RAG 与 Graph RAG 的智能问答系统。系统支持 PDF 解析、文本与表格切分、BM25/向量混合检索、知识图谱检索、LLM 答案生成、多轮对话记忆，以及基于 RAGAS 的检索质量评估。

当前重点能力：

- PDF 正文、表格和图片辅助解析。
- BM25 + 向量检索 + RRF/加权融合。
- Neo4j + 内存知识图谱双后端。
- Graph RAG 子图检索与关系证据输出。
- Redis 短期会话记忆与 Milvus 长期记忆。
- `sample_questions.pdf` 对齐评估与 RAGAS 指标输出。

## 3. 系统架构

系统处理流程：

1. 从 `data/` 读取 PDF。
2. 使用 MinerU/PyMuPDF/pdfplumber 解析正文、表格和页面信息。
3. 生成标准 `Document` 块，记录 `source_file`、`page`、`chunk_id` 等元数据。
4. 构建 BM25 检索索引。
5. 构建向量检索索引。
6. 抽取实体和关系，写入内存图谱，并在 Neo4j 可用时同步到 Neo4j。
7. 用户提问后进行 Query 改写、PDF 来源选择、混合检索和图谱检索。
8. 对上下文去重、重排、压缩。
9. 通过本地规则或 LLM 生成答案。
10. 使用 RAGAS 对上下文精度、上下文召回和响应时间进行评估。

## 4. Graph RAG 模块

Graph RAG 相关代码位于：

- `src/graph_rag/extractor.py`
- `src/graph_rag/graph_store.py`
- `src/graph_rag/retriever.py`

知识图谱实体类型包括：

- `Company`：公司、银行、保险公司、证券公司。
- `Person`：董事长、法定代表人、高管。
- `Organization`：部门、分公司、委员会。
- `Metric`：营业收入、净利润、拨备覆盖率、资本充足率等指标。
- `Strategy`：风险管理、绿色金融、科技金融、资产配置策略等。
- `Value`：金额、比例、数量、日期。

关系记录字段：

- `source`
- `relation`
- `target`
- `confidence`
- `evidence`
- `source_file`
- `page`
- `chunk_id`

## 5. 优化版 RAG 引擎

优化版引擎位于：

```text
src/rag_engine_optimized.py
```

类名：

```python
RAGEngineOptimized
```

该类继承原始 `RAGEngine`，保持 `ask()` 接口兼容。优化点：

- 候选上下文从 `candidate_k=8/final_k=6` 收紧为 `candidate_k=5/final_k=4`。
- 图谱深度从 2 降为 1。
- 对匿名银行问题禁用图谱扩展，避免误命中招股说明书图谱内容。
- 对银行/保险分析题限制候选来源为金融年报集合。
- 对“董事长致辞、盈利增长、创新商业模式、风险管理、资本结构、绿色金融、科技金融”等维度做查询扩展。
- 只优化检索和上下文选择，不固定答案。

重要原则：

```text
系统不得硬编码答案。所有答案必须来自检索上下文、本地抽取规则或 LLM 基于上下文生成。
```

## 6. RAGAS 评估

工单九的正确评估链路是先生成与 `sample_questions.pdf` 对齐的结果，再进行 RAGAS 评估。

生成问答结果：

```powershell
.\.venv\Scripts\python.exe run_sample_questions.py
```

输出：

```text
output\sample_questions_graph_rag_results.json
```

运行 RAGAS 测试：

```powershell
.\.venv\Scripts\python.exe test_ragas_result.py
```

输出：

```text
output\ragas_test_result.json
```

标准评估命令：

```powershell
.\.venv\Scripts\python.exe evaluate_with_ragas.py --results output\sample_questions_graph_rag_results.json
```

输出：

```text
output\ragas_evaluation.json
```

## 7. RAGAS 环境配置

`ragas` 已加入 `requirements.txt`：

```text
ragas>=0.1.21
```

评估脚本会读取 `.env` 中的 OpenAI-compatible 配置：

- `LLM_API_KEY`
- `LLM_API_BASE_URL`
- `LLM_MODEL`

脚本会自动映射为 RAGAS 所需的：

- `OPENAI_API_KEY`
- `OPENAI_BASE_URL`
- `OPENAI_MODEL`

如果真实 RAGAS 调用失败，脚本会记录错误，并回退到本地兼容指标，便于排查。

## 10. 常见问题

### 10.1 评估结果里旧文件太多

清空 `output/` 目录后重新运行：

```powershell
.\.venv\Scripts\python.exe run_sample_questions.py
.\.venv\Scripts\python.exe test_ragas_result.py
```

### 10.2 命中错误 PDF

查看：

```text
source_chunks[].metadata.source_file
```

如果匿名银行题命中招股说明书，说明来源过滤或检索模式需要继续收紧。

### 10.3 响应时间超过 3 秒

优先查看哪道题耗时最高。常见原因：

- 图谱检索候选过多。
- 向量检索后端连接慢。
- RAGAS 评估模型接口响应慢。

### 10.4 RAGAS 报模型不支持

检查 `.env` 中：

- `LLM_MODEL`
- `LLM_API_BASE_URL`
- `LLM_API_KEY`
