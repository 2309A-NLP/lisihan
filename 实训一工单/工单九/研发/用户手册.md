# PDF 金融文档智能问答系统用户手册

## 1. 系统能做什么

本系统用于对招股说明书、年度报告等金融 PDF 进行智能问答。你可以将 PDF 放入 `data/` 目录，系统会解析文档并构建检索索引与知识图谱，然后根据问题返回答案和来源片段。

系统支持：

- PDF 正文解析。
- PDF 表格解析。
- BM25 + 向量混合检索。
- Graph RAG 知识图谱检索。
- 多轮对话记忆。
- RAGAS 评估。
- `sample_questions.pdf` 批量测试。

## 2. 使用前准备

### 2.1 安装依赖

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 2.2 准备 PDF

将需要问答的 PDF 放入：

```text
data/
```

工单九的参考问题 PDF 已放在项目根目录：

```text
sample_questions.pdf
```

### 2.3 启动依赖服务

如果需要 Redis、Milvus 或 Neo4j，请确认服务已经启动。

常用地址：

```text
Redis : localhost:6379
Milvus: localhost:19530
Neo4j : bolt://127.0.0.1:7687
```

## 3. 启动系统

### 3.1 Streamlit 页面

```powershell
.\.venv\Scripts\python.exe main.py
```

或：

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.port 8502
```

浏览器访问：

```text
http://127.0.0.1:8502
```

### 3.2 命令行模式

```powershell
.\.venv\Scripts\python.exe main.py --mode cli
```

## 4. 普通问答

在页面底部输入问题即可。

示例：

```text
平安银行的风险管理体系如何体现其应对宏观经济周期波动的能力？
```

```text
公司注册资本是多少？
```

```text
本次募集资金拟投资哪些项目？
```

回答下方可以查看：

- 命中的上下文。
- 来源 PDF。
- 页码。
- chunk_id。
- 检索分数。
- 响应时间。

## 5. 工单九 sample_questions 测试

如果要按照 `sample_questions.pdf` 进行正式测试，先清空 `output/` 中旧结果，然后按以下顺序运行。

### 5.1 生成问答结果

```powershell
.\.venv\Scripts\python.exe run_sample_questions.py
```

生成：

```text
output\sample_questions_graph_rag_results.json
```

说明：

- 脚本会自动读取 `sample_questions.pdf` 中的问题和参考答案。
- 脚本调用 `RAGEngineOptimized.ask()`。
- 答案不会写死，全部根据检索上下文生成。
- 匿名银行题只做来源过滤和关键词扩展，不固定到某一家银行。

### 5.2 运行 RAGAS 测试

```powershell
.\.venv\Scripts\python.exe test_ragas_result.py
```

生成：

```text
output\ragas_test_result.json
```

结果中重点查看：

- `context_precision`
- `context_recall`
- `average_response_time`
- 每题的 `context_count`
- 每题的来源文件

### 5.3 标准评估命令

```powershell
.\.venv\Scripts\python.exe evaluate_with_ragas.py --results output\sample_questions_graph_rag_results.json
```

生成：

```text
output\ragas_evaluation.json
```

## 6. 如何清空旧结果

如果你想重新测试，可以清空 `output/` 目录中的旧文件，保留目录本身即可。

清空后重新运行：

```powershell
.\.venv\Scripts\python.exe run_sample_questions.py
.\.venv\Scripts\python.exe test_ragas_result.py
```

## 7. 评估目标

| 指标 | 目标 |
| --- | --- |
| context_precision | >= 0.8 |
| context_recall | >= 0.9 |
| average_response_time | <= 3 秒 |

## 8. 常见问题

### 8.1 RAGAS 报模型不支持

检查 `.env`：

```text
LLM_API_KEY
LLM_API_BASE_URL
LLM_MODEL
```

### 8.2 检索到了错误 PDF

打开结果文件：

```text
output\sample_questions_graph_rag_results.json
```

查看：

```text
source_chunks[].metadata.source_file
```

### 8.3 响应时间超过 3 秒

查看每题 `response_time`。如果某一道题耗时明显偏高，优先检查该题是否启用了过深的图谱检索或命中了过多无关候选。

### 8.4 结果不稳定

建议：

1. 清空 `output/`。
2. 重新运行 `run_sample_questions.py`。
3. 再运行 `test_ragas_result.py`。
4. 对比每题来源文件和上下文数量。
