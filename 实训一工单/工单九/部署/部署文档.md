## 7. 优化版引擎使用

### 7.1 运行 sample_questions 批量测试

```powershell
.\\.venv\\Scripts\\python.exe run_sample_questions.py
```

流程：
1. 读取 `sample_questions.pdf` 提取所有 QA 对
2. 初始化 RAGEngineOptimized（自动解析 PDF、构建索引、构建图谱）
3. 逐题通过优化引擎回答
4. 输出结果到 `output/sample_questions_graph_rag_results.json`

参数选项：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--reference-pdf` | sample_questions.pdf | 参考问答 PDF |
| `--output` | output/sample_questions_graph_rag_results.json | 输出路径 |
| `--retrieval-mode` | hybrid_graph_optimized | 检索模式 |
| `--answer-language` | zh | 回答语言 |
| `--no-init` | 无 | 跳过知识库初始化 |

### 7.2 优化版引擎能力

`RAGEngineOptimized` 继承自工单八的 `RAGEngine`，新增：

| 优化项 | 说明 |
| --- | --- |
| **OptimizedContextSelector** | 上下文去重、加权重排、预算打包 |
| **智能权重** | BM25=0.72 / 向量=0.28，金融文档精确优先 |
| **查询扩展** | 自动补充领域关键词（如"收入"→"主营业务收入 销售额"） |
| **来源过滤** | 按题目类型限定检索 PDF 范围 |
| **时间保护** | 检索超 5 秒自动截断图谱分支 |
| **Unicode 规范化** | 处理特殊字符（⻓→长、⻛→风） |
| **自适应重排** | 结合用户反馈动态调整排序 |

## 8. RAGAS 评估

### 8.1 评估流程

```
run_sample_questions.py  →  sample_questions_graph_rag_results.json
         ↓
evaluate_with_ragas.py   →  ragas_evaluation.json（含 context_precision/recall）
         ↓
evaluate_optimized.py    →  optimization_comparison.json（基线 vs 优化对比）
```

### 8.2 运行 RAGAS 评估

```powershell
# 标准评估（使用 sample_questions 结果）
.\\.venv\\Scripts\\python.exe evaluate_with_ragas.py

# 指定评估已有结果
.\\.venv\\Scripts\\python.exe evaluate_with_ragas.py --results output\work_order_8_results.json

# 跳过 RAGAS（使用本地兼容评估器）
.\\.venv\\Scripts\\python.exe evaluate_with_ragas.py --no-ragas
```

### 8.3 运行优化对比

```powershell
# 离线优化对比（对已有结果应用优化上下文选择器）
.\\.venv\\Scripts\\python.exe evaluate_optimized.py

# 实时优化对比（重新通过 RAGEngineOptimized 运行）
.\\.venv\\Scripts\\python.exe evaluate_optimized.py --live

# 自定义结果和输出
.\\.venv\\Scripts\\python.exe evaluate_optimized.py ^
  --results output\sample_questions_graph_rag_results.json ^
  --output output\optimization_comparison.json
```

### 8.4 评估指标与验收标准

| 指标 | 目标值 | 评估方式 |
| --- | --- | --- |
| context_precision | ≥ 0.8 | RAGAS / 本地兼容评估 |
| context_recall | ≥ 0.9 | RAGAS / 本地兼容评估 |
| average_response_time | ≤ 3s | JSON 结果中的时间字段 |

### 8.5 RAGAS 配置注意

RAGAS 需要 LLM 支持 OpenAI 兼容 API。`evaluate_with_ragas.py` 会自动从 `.env` 读取：

```
LLM_API_KEY     → OPENAI_API_KEY
LLM_API_BASE_URL → OPENAI_BASE_URL
LLM_MODEL       → OPENAI_MODEL
```

如果 LLM 不支持 RAGAS 所需指标，脚本会自动降级到本地兼容评估器。

### 8.6 输出文件说明

| 文件 | 生成脚本 | 内容 |
| --- | --- | --- |
| `output/sample_questions_graph_rag_results.json` | `run_sample_questions.py` | 优化引擎问答结果（含答案、片段、图谱信息） |
| `output/ragas_evaluation.json` | `evaluate_with_ragas.py` | RAGAS/本地评估结果（含 summary 和 detail） |
| `output/optimization_comparison.json` | `evaluate_optimized.py` | 基线 vs 优化对比表 |

## 10. 常见问题

### 10.1 RAGAS 报错

```
ModuleNotFoundError: No module named 'ragas'
```
**解决**：`pip install ragas datasets langchain-openai`

### 10.2 RAGAS API 调用失败

```
OpenAI API connection error
```
**解决**：
1. 检查 `.env` 中的 `LLM_API_BASE_URL` 和 `LLM_API_KEY`
2. 使用 `--no-ragas` 降级到本地评估

### 10.3 sample_questions.pdf 无输出

```
No questions parsed from sample_questions.pdf
```
**解决**：
1. 确认文件存在且不为空
2. 检查 PDF 中是否包含"问题："和"参考答案："格式

### 10.4 响应时间超过 3 秒

**解决**：
1. 检查 `max_retrieval_seconds` 配置（默认 5s）
2. 查看 `sample_questions_graph_rag_results.json` 中每题的 `response_time`
3. 减少 `candidate_k` 或 `graph_depth`
