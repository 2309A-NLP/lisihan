# 🚀 PDF 招股说明书智能问答系统 — 部署文档

> **项目名称：** 问答系统5 · PDF RAG 智能问答系统
> **技术栈：** Python 3.12 · Streamlit · BM25 · Milvus · Redis · PyMuPDF · Mimo v2.5 Pro LLM

---

## 1. 系统概述

面向招股说明书 PDF 的 RAG 智能问答系统。用户上传 PDF（已将两份招股说明书解析入库），系统通过 **BM25 + Milvus 向量检索 + RRF 融合** 的混合检索方式，结合 **Mimo v2.5 Pro** LLM 生成精确答案。

**核心能力：**

- 📄 **PDF 全文解析** — 正文、表格、图片、元数据一站式抽取
- 🔍 **混合检索** — BM25 精确匹配 + Milvus 语义向量 + RRF 融合排序
- 🧠 **智能问答** — 问题分类、指代消解、查询改写、规则抽取 + LLM 生成
- 🖼️ **多模态支持** — 图片/表格/组织结构图的多模态大模型理解
- 💾 **双层记忆** — Redis 短期对话记忆 + Milvus 长期优质问答记忆
- 🌐 **Web 界面** — Streamlit 交互式问答面板，支持检索调试查看

## 9. 常见问题排查

### Q1: 页面打开后显示"知识库为空"

```
检查点：data\ 目录下是否有 PDF 文件
解决：将 PDF 放入 data\ 目录，重启应用
```

### Q2: 容器无法启动（端口被占用）

```powershell
# 检查端口占用
netstat -ano | findstr :6379
netstat -ano | findstr :19530

# 在 docker-compose.yml 中修改端口映射
```

### Q3: LLM 调用超时或报错

```
检查点：.env 中 LLM_API_KEY 是否正确
解决：检查网络连通性，或替换为其他兼容 OpenAI API 的 LLM
```

### Q4: 答案不准确

```
检查点：在 Web 界面展开"检索片段"，确认命中的上下文是否正确
解决：调整 BM25_K / VECTOR_K / RRF_K 等检索参数
```

### Q5: pip 安装太慢

```powershell
# 使用清华镜像
.\.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q6: main.py 报错"检测到当前 Python 环境不是本项目 .venv"

```
这是正常行为，main.py 会自动切换到 .venv\Scripts\python.exe
如果报错，请确保 .venv\Scripts\python.exe 存在
```

### Q7: 启动后 Redis 相关警告

```
系统会自动降级，不影响问答功能。
如需关闭 Redis，设置 ENABLE_MILVUS_DOCUMENT_STORE=false
或在 .env 中注释掉 REDIS_URL
```

### Q8: 如何更换 LLM？

```powershell
# 修改 .env 文件
LLM_API_BASE_URL=https://api.openai.com/v1
LLM_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx
LLM_MODEL=gpt-4o-mini
# 然后重启应用
```
