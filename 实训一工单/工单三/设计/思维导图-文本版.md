# PDF 招股说明书智能问答系统 — 思维导图（文本版）

```
                            ┌─ 📋 系统概述
                            │   ├── 基于 RAG 的 PDF 问答系统
                            │   ├── 针对招股说明书设计
                            │   ├── 自然语言提问→检索→生成回答
                            │   └── 工单：NLP-RAG-PDF问答系统
                            │
                            ├─ ⚡ 核心功能
                            │   ├── PDF 解析：MinerU / PyMuPDF 回退
                            │   ├── 4 种切块策略：段落/标题/父子/递归
                            │   ├── 混合检索：BM25 + 向量 + RRF 融合
                            │   ├── 记忆系统：Redis 短期 + Milvus 长期
                            │   ├── 回答策略：元数据直答→规则抽取→LLM
                            │   └── 工单问题批量评估与对比分析
                            │
                            ├─ 🏗 技术架构
                            │   ├── Streamlit 前端 (port 8502)
            ┌─ PDF 招股说明书 ─┼─  ├── RAG 引擎 (rag_engine.py)
            │  智能问答系统    │   ├── HybridRetriever (BM25+Milvus)
            │                 │   ├── LLM Engine (SiliconFlow API)
            │                 │   ├── sentence-transformers 嵌入模型
            │                 │   └── Redis + Milvus (Docker 容器)
            │                 │
            │                 ├─ 📁 目录结构
            │                 │   ├── data/           — PDF 原文
            │                 │   ├── pdf_parser/     — PDF 解析
            │                 │   ├── src/            — 核心业务
            │                 │   ├── utils/          — LLM/评估/日志
            │                 │   ├── app.py          — Streamlit
            │                 │   └── main.py         — 启动入口
            │                 │
            │                 ├─ ▶ 运行模式
            │                 │   ├── Web 模式   — streamlit (8502)
            │                 │   ├── CLI 模式   — main.py --mode cli
            │                 │   └── 工单测试   — test_工单问题.py
            │                 │
            │                 ├─ 🔧 依赖服务
            │                 │   ├── Redis  (6379)  — 短期记忆
            │                 │   ├── Milvus (19530) — 向量数据库
            │                 │   ├── SiliconFlow API — LLM 服务
            │                 │   └── MinerU (WSL)   — PDF 解析
            │                 │
            │                 ├─ 🚀 部署流程
            │                 │   ├── 1. python -m venv .venv
            │                 │   ├── 2. pip install -r requirements.txt
            │                 │   ├── 3. docker compose up -d
            │                 │   ├── 4. 配置 .env (API Key)
            │                 │   ├── 5. 放置 PDF 到 data/
            │                 │   └── 6. python main.py 启动
            │                 │
            │                 └─ ⚙ 配置管理
            │                     ├── .env           — API Key/模型
            │                     ├── src/config.py  — 检索/切块参数
            │                     ├── 侧边栏 Streamlit — 动态调整
            │                     └── 切块策略/大小/重叠/检索模式
            │
            └─ 📄 数据文件
                ├── data/*.pdf              — PDF 原文
                ├── parsed_pdfs/*.json      — 解析结果缓存
                ├── mineru_output/          — MinerU 输出
                ├── logs/app.log            — 运行日志
                └── 工单问题测试结果.json     — 评估输出
```
