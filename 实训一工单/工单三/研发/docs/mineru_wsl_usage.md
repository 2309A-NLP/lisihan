# WSL MinerU Usage

This project can call MinerU installed in WSL from Windows/PyCharm. The data
flow is:

```text
PDF -> MinerU Markdown/content_list -> parsed_pdfs/*_chunks.json -> RAG
```

The final JSON keeps `mineru_markdown_path`, so you can always trace chunks
back to the Markdown generated by MinerU.

## PyCharm Script

Run:

```powershell
.\.venv\Scripts\python.exe examples\parse_pdf_with_mineru_wsl.py data\招股说明书1.pdf
```

The script writes chunks to `parsed_pdfs` and uses MinerU cache from
`mineru_output` when available.

## RAG Initialization

`pdf_parser.main.PDFParser` now prefers MinerU automatically. Existing app code
can keep calling:

```python
from pdf_parser.main import PDFParser

docs = PDFParser().parse_pdf(r"data\招股说明书1.pdf")
```

Chunking options are shared with the PyMuPDF fallback path:

```python
docs = PDFParser(
    chunk_size=500,
    chunk_overlap=50,
    chunk_strategy="title",  # paragraph, title, parent_child, recursive
).parse_pdf(r"data\招股说明书1.pdf")
```

## Configuration

Set these environment variables when your WSL setup differs from the defaults:

```powershell
$env:ENABLE_MINERU_WSL="true"
$env:MINERU_OUTPUT_DIR="./mineru_output"
$env:MINERU_WSL_CONDA_PREFIX="/home/li/miniconda3"
$env:MINERU_WSL_CONDA_ENV="base"
$env:MINERU_WSL_DISTRO=""
$env:MINERU_METHOD="auto"
$env:MINERU_USE_CACHE="true"
```

If MinerU fails, the parser falls back to the original PyMuPDF path.
