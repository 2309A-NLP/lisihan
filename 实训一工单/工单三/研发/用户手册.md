# PDF 招股说明书智能问答系统用户手册

工单编号：人工智能 NLP-RAG-基于 PDF 文档的问答系统

## 1. 系统能做什么

本系统用于对 `data/` 目录中的招股说明书 PDF 进行智能问答。

支持能力：

- PDF 正文和表格解析。
- 招股说明书固定信息直答。
- BM25 + Milvus 混合检索。
- 中文 / 英文回答切换。
- 多种切块方式：段落/句子、标题、父子块、递归。
- Redis 短期对话展示。
- Milvus 长期优质问答记忆。
- 工单问题批量评估。

典型问题：

- 法定代表人是谁？
- 注册资本是多少？
- 参与制定了哪个技术标准？
- 军用领域收入分别是多少？
- 收入占主营业务收入的比重分别是多少？
- 上游涉及哪些企业？
- 下游主要包括哪些行业？
- 哪个工程荣获了国家科技进步一等奖？

## 2. 使用前准备

把 PDF 放入：

```text
data/
```

启动 Redis 和 Milvus：

```powershell
docker compose up -d
```

安装依赖：

```powershell
cd C:\Users\freedom\Desktop\问答系统3
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 3. 启动系统

Web 页面：

```powershell
cd C:\Users\freedom\Desktop\问答系统3
.\.venv\Scripts\python.exe main.py
```

默认访问：

```text
http://localhost:8502
```

命令行演示：

```powershell
.\.venv\Scripts\python.exe main.py --mode cli
```

## 4. 页面配置

侧边栏可以配置：

- 切块方式
- 切块大小
- 切块重叠
- 当前检索模式
- 回答语言

切块方式说明：

| 选项 | 适用场景 |
| --- | --- |
| 段落/句子切块 | 默认方式，适合稳定、快速的常规问答 |
| 标题切块 | 文档标题层级清晰时使用，适合章节型问题 |
| 父子块切块 | 需要保留章节上下文时使用，适合长章节检索 |
| 递归切块 | 文本长短不均时使用，适合更均匀的 chunk |

更改切块设置后，点击：

```text
按当前切块方式重新解析并构建索引
```

系统会重新解析 PDF 并构建检索索引。

## 5. 提问与调试

在页面底部输入问题即可提问。

回答下方可查看：

- 响应时间
- 置信度估算
- 答案来源
- 问题类型
- 检索模式
- 命中的检索片段

如果回答不符合预期，优先展开“查看检索片段”，确认系统是否命中了正确原文。

## 6. PDF 解析输出

解析结果输出到：

```text
parsed_pdfs/
```

常见文件：

```text
parsed_pdfs/*_chunks.json
parsed_pdfs/*_metadata.json
```

`*_chunks.json` 中会包含：

- `content`
- `page`
- `bbox`
- `chunk_id`
- `chunk_strategy`
- `heading_path`
- `parent_id`
- `metadata`

不同切块方式会产生不同的 `metadata` 字段。父子块切块会额外包含 `chunk_level`、`parent_id`、`parent_title`、`parent_preview`。

## 7. 固定信息直答

以下问题优先使用元数据回答，不依赖普通检索：

| 问题 | 答案来源 |
| --- | --- |
| 公司名称是什么？ | metadata |
| 法定代表人是谁？ | metadata |
| 注册资本是多少？ | metadata |
| 公司成立日期是什么？ | metadata |
| 注册地址在哪里？ | metadata |

这样可以减少表格、银行信息、中介机构信息对答案的干扰。

## 9. 常见问题

知识库未初始化：

- 检查 `data/` 是否存在 PDF。
- 检查 PDF 是否可打开。
- 查看 `logs/app.log`。
- 点击“按当前切块方式重新解析并构建索引”。

Redis 不可用：

```powershell
netstat -ano | Select-String ":6379"
```

Milvus 不可用：

```powershell
netstat -ano | Select-String ":19530"
```

MinerU 不可用：

- 检查 WSL 是否安装 MinerU。
- 检查 `MINERU_WSL_CONDA_PREFIX` 和 `MINERU_WSL_CONDA_ENV`。
- MinerU 失败时系统会自动回退 PyMuPDF，不影响基本运行。

回答跑偏：

1. 展开“查看检索片段”。
2. 检查 `parsed_pdfs/*_chunks.json` 是否包含正确原文。
3. 尝试调整切块方式。
4. 对精确问题优先检查 `metadata_extractor.py`、`query_rewriter.py` 和 `llm_engine.py`。

## 10. 文件说明

| 文件/目录 | 作用 |
| --- | --- |
| `main.py` | 启动入口 |
| `app.py` | Streamlit 页面 |
| `data/` | PDF 原文目录 |
| `parsed_pdfs/` | 解析结果目录 |
| `mineru_output/` | MinerU 缓存目录 |
| `pdf_parser/` | PDF 解析和切块模块 |
| `src/rag_engine.py` | RAG 主流程 |
| `src/retriever.py` | BM25 + Milvus + RRF 检索 |
| `utils/llm_engine.py` | LLM 调用、规则抽取和后处理 |
| `test_工单问题.py` | 工单问题测试脚本 |
| `工单问题测试结果.json` | 最新测试结果 |

## 11. 注意事项

- 不要删除 `data/` 中仍需问答的 PDF。
- 删除 `parsed_pdfs/` 后需要重新解析 PDF。
- 更改切块方式后必须重新构建索引。
- 固定字段问题优先走元数据，不依赖 LLM。
- 精确数值和比例问题会优先走规则与 BM25 快速路径。
