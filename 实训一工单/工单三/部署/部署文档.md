## 1. 系统概述

本项目是一个基于 **RAG（检索增强生成）** 的 PDF 智能问答系统，专为招股说明书等 PDF 文档设计。用户可以用自然语言提问，系统从 PDF 中检索相关内容，通过 LLM 生成精确回答。

**核心能力：**

- 📄 **PDF 解析**：支持 MinerU（WSL）高精度解析 + PyMuPDF/pdfplumber 回退
- 🔍 **混合检索**：BM25 + Milvus 向量检索 + RRF 加权融合
- 🧠 **记忆系统**：Redis 短期对话记录 + Milvus 长期优质问答持久化
- 🎯 **精准回答**：元数据直答、规则抽取、LLM 上下文生成多级策略
- 📊 **评估能力**：内置工单问题批量测试与对比分析
- 🌐 **Web 界面**：Streamlit 交互式页面，支持切块参数动态调整

## 3. 快速部署（一键启动）

以下是最简步骤，适合已有环境的快速启动：

```powershell
# 1. 进入项目目录
```

## 4. 详细部署步骤

### 4.1 安装依赖

#### 4.1.1 创建 Python 虚拟环境

```powershell
cd C:\Users\freedom\Desktop\问答系统3
python -m venv .venv
```

#### 4.1.2 安装 Python 依赖

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**关键依赖包清单：**

| 包名 | 用途 |
|------|------|
| `streamlit` | Web 界面框架 |
| `rank-bm25` | BM25 检索 |

> **注意：** `sentence-transformers` 会自动下载嵌入模型。如果遇到网络问题，建议先手动下载模型到本地路径，然后在 `.env` 中配置 `EMBEDDING_MODEL_PATH` 指向本地路径。

#### 4.1.3 安装向量模型（离线方式）

如果无法在线下载嵌入模型，可从 ModelScope 下载：

```powershell

.\.venv\Scripts\python.exe -m pip install modelscope

# 下载 bge-base-zh-v1.5 模型
.\.venv\Scripts\python.exe -m modelscope download --model AI-ModelScope/bge-base-zh-v1.5 --local_dir C:\Users\freedom\Desktop\专业\模型\bge-base-zh-v1.5
```

### 4.2 配置环境变量

复制 `.env` 文件到项目根目录，修改以下关键配置：

```ini
# LLM 配置
LLM_PROVIDER=siliconflow                 # LLM 厂商
LLM_API_BASE_URL=https://api.siliconflow.cn/v1  # API 地址
SILICONFLOW_API_KEY=sk-xxxxxxxxxxxx      # API 密钥（请填写有效密钥）
LLM_MODEL=deepseek-ai/DeepSeek-V4-Flash  # 模型名称

# 嵌入模型路径（默认使用本地路径）
EMBEDDING_MODEL_PATH=C:\Users\freedom\Desktop\专业\模型\bge-base-zh-v1.5

# 检索配置
BM25_COLLECTION=pdf_documents            # 索引名称
TOP_K_RETRIEVAL=3                        # 最终召回条数
BM25_K=6                                 # BM25 候选数
VECTOR_K=4                               # 向量候选数

# Redis
REDIS_URL=redis://localhost:6379/0

# Milvus
MILVUS_URI=http://localhost:19530

# PDF 解析
PDF_DIR=./data                           # PDF 存放目录
ENABLE_MINERU_WSL=true                   # 是否启用 MinerU WSL 解析
```

**LLM API Key 获取方式：**

| 厂商 | 注册地址 | 说明 |
|------|---------|------|
| SiliconFlow | https://cloud.siliconflow.cn | 推荐，国内可访问，支持 DeepSeek 等主流模型 |
| OpenAI | https://platform.openai.com | 需海外网络 |
| DeepSeek | https://platform.deepseek.com | DeepSeek 官方 |
| 任何 OpenAI 兼容 API | — | 修改 `LLM_API_BASE_URL` 和 `LLM_API_KEY` |

将招股说明书 PDF 文件放入 `data\` 目录：

## 5. 运行模式说明

### 5.1 Web 模式（Streamlit）

**默认运行模式**，提供完整的交互式界面。

**访问地址：** `http://localhost:8502`

**界面功能：**

| 区域 | 功能说明 |
|------|---------|
| **侧边栏—配置面板** | 切块策略、切块大小、重叠数、检索模式、回答语言 |
| **侧边栏—知识库状态** | 显示索引文件数和初始化状态 |
| **侧边栏—重新解析** | 修改切块参数后点击重建索引 |
| **侧边栏—对话历史** | 查看最近 20 条 Redis 短期记忆 |
| **侧边栏—长期记忆** | 查看 Milvus 中存储的优质问答 |
| **侧边栏—工单评估** | 运行内置工单问题批量测试 |
| **主区域** | 对话输入框 + 聊天界面 + 反馈按钮 |

**检索模式切换：**

| 模式 | 说明 |
|------|------|
| 混合检索（hybrid） | BM25 + 向量 + RRF 融合（默认，推荐） |
| BM25 检索 | 仅使用 BM25 关键词检索 |
| 向量检索 | 仅使用 Milvus 向量检索 |

**切块策略说明：**

| 策略 | 适用场景 |
|------|---------|
| 段落/句子切块 | 通用场景，默认推荐 |
| 标题切块 | 文档有清晰章节结构（如招股书） |
| 父子块切块 | 需要保持上下文连贯性的问答 |
| 递归切块 | 内容层次复杂，需要精细控制 |

### 5.2 CLI 模式

```powershell
.\.venv\Scripts\python.exe main.py --mode cli
```

命令行模式下，系统会：
1. 自动初始化知识库
2. 按内置工单问题列表逐条执行
3. 对比 RAG 回答与纯 LLM 回答
4. 输出评估报告（相关性、忠实度、综合评分、RAG 对比值）

### 5.3 工单批量测试

```powershell
.\.venv\Scripts\python.exe test_工单问题.py
```

运行后将生成 `工单问题测试结果.json`，包含每个问题的详细评估数据。

## 7. 常见问题排查

### 7.1 知识库初始化失败

**现象：** 页面显示"知识库尚未初始化"，或提示"项目中没有可解析的PDF文档"

**排查步骤：**
1. 检查 `data\` 目录下是否存在 `.pdf` 文件
2. 检查日志：`logs\app.log`
3. 确认 PDF 文件未被其他程序占用

### 7.2 Streamlit 无法启动

**现象：** `streamlit run` 报错或端口被占用

**解决办法：**
```powershell
# 查看 8502 端口占用
netstat -ano | findstr :8502

# 强制结束占用进程
taskkill /PID <进程ID> /F

# 或更换端口启动
.\.venv\Scripts\python.exe -m streamlit run app.py --server.port 8503
```

### 7.3 Redis 连接失败

**现象：** 页面显示"Redis 短期记忆不可用"

**解决办法：**
```powershell
# 确认 Redis 容器在运行
docker ps | findstr redis

# 若未运行，启动容器
docker compose up -d redis

# 测试连接
docker exec -it <容器名> redis-cli ping
# 应返回 PONG
```

### 7.4 Milvus 连接失败

**现象：** 页面显示"Milvus 长期记忆不可用"

**解决办法：**
```powershell
# 确认 Milvus 容器在运行
docker ps | findstr milvus

# 查看 Milvus 日志
docker logs <milvus容器名>

# 测试连接（检查端口）
Test-NetConnection -ComputerName localhost -Port 19530
```

> **注意：** Milvus 首次启动需要约 30-60 秒初始化（下载模型、创建索引），请耐心等待。

### 7.5 LLM 调用失败

**现象：** 回答为空，或显示"回答生成失败"

**排查步骤：**
1. 检查 `.env` 中的 API Key 是否正确
2. 确认网络能访问 `api.siliconflow.cn`
3. 尝试直接用 curl 测试：
   ```powershell
   curl -X POST https://api.siliconflow.cn/v1/chat/completions `
     -H "Authorization: Bearer $env:SILICONFLOW_API_KEY" `
     -H "Content-Type: application/json" `
     -d '{\"model\":\"deepseek-ai/DeepSeek-V4-Flash\",\"messages\":[{\"role\":\"user\",\"content\":\"你好\"}]}'
   ```
4. 检查账户余额是否充足

### 7.6 回答质量不佳

**排查方向：**
1. **检索片段不正确**：展开调试信息，查看"查看检索片段"命中的内容
2. **切块参数不合适**：在侧边栏调整切块策略/大小/重叠后重新解析
3. **无相关上下文**：确认 PDF 中确实包含相关信息
4. **回答语言不对**：检查"回答语言"设置（中文/English）
5. **LLM 模型太弱**：更换更强的模型（如 DeepSeek-V3、GPT-4o）

### 7.7 MinerU 解析失败

**现象：** PDF 解析很慢或失败

**处理方式：**
- 系统会自动回退到 PyMuPDF + pdfplumber 解析，不影响使用
- 如需启用 MinerU，请参考 `docs/mineru_wsl_usage.md`
- 可在 `.env` 中设置 `ENABLE_MINERU_WSL=false` 跳过 MinerU

### 7.8 嵌入模型加载失败

**现象：** 向量检索不可用

**解决办法：**
```powershell
# 确认模型路径是否存在
Test-Path "C:\Users\freedom\Desktop\专业\模型\bge-base-zh-v1.5"

# 如果不存在，手动下载
# 见 4.1.3 节"安装向量模型（离线方式）"
```
