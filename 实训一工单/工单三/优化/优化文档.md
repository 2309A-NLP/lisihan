## 4. 优化建议详细方案

### 4.1 高优先级：异步 LLM 调用

**现状问题：**
`LLMEngine._init_client()` 使用同步 `OpenAI()`，每次 LLM 调用会阻塞整个 RAG 流程。在并发场景下（多人同时提问），请求排队导致整体响应时间线性增长。

**改动方案：**
```python
# utils/llm_engine.py
from openai import AsyncOpenAI

class LLMEngine:
    def _init_client(self):
        # 改为 AsyncOpenAI
        return AsyncOpenAI(
            api_key=Config.LLM_API_KEY,
            base_url=Config.LLM_API_BASE_URL,
            timeout=Config.LLM_TIMEOUT,
            max_retries=1,
        )

    async def _call_llm_async(self, prompt: str) -> str:
        response = await self.client.chat.completions.create(
            model=self.model_name,
            messages=[{"role": "user", "content": prompt}],
            max_tokens=Config.LLM_MAX_TOKENS,
        )
        return response.choices[0].message.content
```

**风险：** RAG 引擎当前为同步流程，改为异步需要联动修改 `rag_engine.py` 中 `ask()` 和 `answer()` 方法。建议分两步走：先改 LLM 引擎层，再改 RAG 引擎层。

### 4.2 中优先级：Cross-encoder Re-ranker

**现状问题：**
BM25 和向量检索的初筛结果排序基于简单的分数叠加，有时会将不相关的片段排到前面。

**改动方案：**
```python
# src/retriever.py 新增 re-rank 方法
from sentence_transformers import CrossEncoder

class HybridRetriever:
    def __init__(self):
        self._reranker = None

    def _load_reranker(self):
        if self._reranker is None:
            self._reranker = CrossEncoder(
                "BAAI/bge-reranker-v2-m3",
                max_length=512,
            )
        return self._reranker

    def rerank(self, query: str, candidates: List[Tuple[Document, float]], top_k: int = 3):
        reranker = self._load_reranker()
        pairs = [(query, doc.page_content) for doc, _ in candidates]
        scores = reranker.predict(pairs)
        ranked = sorted(
            zip(candidates, scores),
            key=lambda x: x[1],
            reverse=True,
        )
        return [(doc, float(score)) for (doc, _), score in ranked[:top_k]]
```

**注意：** Cross-encoder 推理比 BM25/向量慢（CPU 上约 50-100ms/对），建议只在 Top-10 候选中重排，不影响整体延迟过多。

### 4.3 高优先级：嵌入模型预加载

**现状问题：**
`sentence-transformers` 模型在首次调用 `_load_embedding_model()` 时加载，耗时 3-8 秒，导致第一个查询响应极慢。

**改动方案：**
在 `RAGEngine.__init__()` 或 `main.py` 启动时主动调用一次嵌入模型 warmup：

```python
# src/retriever.py 新增 warmup 方法
def warmup_embedding(self):
    model = self._load_embedding_model()
    if model:
        # 调用一次空编码触发模型加载
        _ = model.encode([""])
        logger.info("embedding model warmed up | model=%s", Config.EMBEDDING_MODEL)
        return True
    return False
```

或在 `main.py` 启动时：

```python
# main.py
from src.retriever import HybridRetriever
retriever = HybridRetriever()
retriever.warmup_embedding()  # 启动时预加载
```
