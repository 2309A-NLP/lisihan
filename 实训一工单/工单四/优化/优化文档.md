## 1. v3 → v4 版本演进概览

问答系统4 在保留问答系统3 全部能力的基础上，新增了**多模态图片问答**、**视觉PDF解析**两大核心能力，并完成了**全面模块化重构**。

| 维度 | v3 | v4 | 优化类型 |
|------|----|----|---------|
| **图片问答** | ❌ 不支持 | ✅ 组织结构图、IC市场增长图分析 | 新增功能 |
| **PDF 视觉解析** | ❌ 不支持 | ✅ 区域检测、渲染、提取 | 新增功能 |
| **架构** | 单文件 (rag_engine.py等) | Mixin 包结构 (rag_engine/等) | 重构优化 |
| **MinerU** | 可选后端，失败降级 | 强制主后端，可配置降级 | 稳定性加强 |
| **LLM 供应商** | SiliconFlow (DeepSeek) | 小米 MiMo (mimo-v2.5-pro) | 提供商切换 |
| **多模态模型** | ❌ 无 | ✅ mimo-v2.5 | 新增能力 |
| **缓存** | 答案缓存 (30s TTL) | + 多模态Redis缓存 (1h TTL) | 性能优化 |
| **Milvus** | 仅长期记忆 | + 文档存储 | 架构扩展 |

## 5. 优化建议详细方案

### 5.1 高优先级：异步多模态调用

**现状问题：**
`MultimodalImageParser.ask()` 使用同步 `requests.post()`，超时设置 60 秒。在多模态图片分析期间，整个 RAG 引擎被阻塞，无法处理其他请求。

**改动方案：**

```python
# src/multimodal/image_parser.py
import httpx
from typing import Optional

class MultimodalImageParser:
    def __init__(self, ...):
        self._client = None  # 延迟初始化
    
    @property
    def client(self) -> httpx.AsyncClient:
        if self._client is None:
            self._client = httpx.AsyncClient(timeout=60.0)
        return self._client
    
    async def ask_async(self, image_path: str, question: str) -> str:
        base64_image = self.image_to_base64(image_path)
        response = await self.client.post(
            f"{self.base_url}/chat/completions",
            headers={"Authorization": f"Bearer {self.api_key}", "Content-Type": "application/json"},
            json={
                "model": self.model,
                "messages": [{
                    "role": "user",
                    "content": [
                        {"type": "image_url", "image_url": {"url": f"data:image/png;base64,{base64_image}"}},
                        {"type": "text", "text": question},
                    ],
                }],
                "max_tokens": self.max_tokens,
                "temperature": 0.1,
            },
        )
        response.raise_for_status()
        result = response.json()
        return result["choices"][0]["message"]["content"]
    
    async def close(self):
        if self._client:
            await self._client.aclose()
```

### 5.3 中优先级：多模态图片自动发现

**现状问题：**
图片需要手动在 `MULTIMODAL_WORK_ORDER_IMAGES` 中配置路径、页码等。用户新增 PDF 后，新文档中的图片无法自动用于问答。

**改动方案：**

```python
# src/rag_engine/multimodal.py 新增自动发现
class MultimodalMixin:
    def _auto_discover_images(self) -> Dict[str, Dict]:
        """自动扫描 mineru_output/images/ 目录发现图片。"""
        images = {}
        image_dir = Path(Config.IMAGES_EXTRACT_DIR)
        if not image_dir.exists():
            return images
        
        # 扫描所有 PDF 对应的 parsed JSON，提取图片元数据
        for json_path in Path(Config.PDF_PARSE_OUTPUT_DIR).glob("*_chunks.json"):
            try:
                parsed = json.loads(json_path.read_text(encoding="utf-8"))
                for img in parsed.get("images", []):
                    img_path = img.get("path", "")
                    if img_path and Path(img_path).exists():
                        # 根据图片所在页面的文本内容自动生成标题
                        page = img.get("page", 0)
                        title = self._infer_image_title(parsed, page)
                        key = f"auto_{Path(img_path).stem}"
                        images[key] = {
                            "path": img_path,
                            "page": page,
                            "source_file": img.get("source_file", ""),
                            "title": title or f"page_{page}_image",
                        }
            except Exception:
                continue
        return images
    
    def _infer_image_title(self, parsed: Dict, page: int) -> str:
        """根据页面内容推断图片标题。"""
        for chunk in parsed.get("chunks", []):
            if chunk.get("page") == page:
                content = str(chunk.get("content", ""))
                # 查找"图 X ..." 或 "Figure X" 模式
                import re
                match = re.search(r"[图F][^。\n]{2,50}", content)
                if match:
                    return match.group(0).strip()
        return ""
```

### 5.4 中优先级：动态视觉表格渲染

**现状问题：**
当 RAG 检索到的文本 chunk 包含表格（Markdown 格式混乱），用户看到的是乱序的管道符和数字。此时如果能自动将原 PDF 页面的表格区域渲染为图片，发给多模态模型，准确性会大幅提升。

**改动方案：**

```python
# src/rag_engine/context.py 新增表格检测逻辑
class ContextMixin:
    def _is_table_content(self, content: str) -> bool:
        """检测文本中是否包含表格内容。"""
        pipe_count = content.count("|")
        numeric_cells = len(re.findall(r"\|\s*\d", content))
        return pipe_count > 6 and numeric_cells > 2
    
    def _build_context(self, question: str, ...):
        analysis, context, context_parts, scores, source_chunks = self._build_context_impl(...)
        
        # 检测是否有表格内容 → 尝试视觉渲染
        for i, chunk in enumerate(context_parts):
            if self._is_table_content(chunk) and i < len(source_chunks):
                metadata = source_chunks[i].get("metadata", {})
                source_file = metadata.get("source_file", "")
                page = metadata.get("page", 0)
                if source_file and page:
                    pdf_path = str(Path(Config.PDF_DIR) / source_file)
                    rendered = render_pdf_page_to_image(pdf_path, page, Config.IMAGES_EXTRACT_DIR)
                    if rendered:
                        # 将渲染图信息加入 context，后续由多模态处理
                        analysis["table_render"] = rendered
        
        return analysis, context, context_parts, scores, source_chunks
```
