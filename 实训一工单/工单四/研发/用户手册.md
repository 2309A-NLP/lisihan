# PDF招股说明书智能问答系统用户手册

工单编号：人工智能 NLP-RAG-图像内容解析及检索优化

## 1. 系统用途

本系统用于对招股说明书 PDF 进行智能问答。你可以在网页中提问，系统会从 PDF 正文、表格、固定元数据和图片页面中检索或解析答案。

当前支持：

- 中文/英文回答选择
- 混合检索、BM25 检索、向量检索
- 固定信息直答，如法定代表人、注册资本
- 表格金额、比例、募集资金等问题抽取
- 图片/图表类问题解析
- 最近 20 条短期对话历史查看
- 长期优质问答记忆查看
- 工单问题批量评估

## 2. 使用前准备

### 2.1 放入 PDF

将 PDF 放入：

```text
data/
```

当前项目已包含示例文件：

```text
data/招股说明书1.pdf
data/招股说明书2.pdf
```

### 2.2 重新运行 MinerU 解析

当前主流程使用 MinerU，并把原始 `.md`、`content_list.json` 以及项目适配后的 `*_chunks.json` 都保存在 `mineru_output/`。清理缓存后可以一次解析整个 `data` 目录：

```powershell
.\.venv\Scripts\python.exe run_mineru_wsl.py data --output-dir mineru_output
```

默认模型源为魔塔 ModelScope，解析后端为 MinerU `pipeline`。如果需要临时覆盖，可以追加：

```powershell
.\.venv\Scripts\python.exe run_mineru_wsl.py data --output-dir mineru_output --model-source modelscope --backend pipeline
```

解析成功后应能看到类似文件：

```text
mineru_output/招股说明书1/auto/招股说明书1.md
mineru_output/招股说明书1/auto/招股说明书1_content_list.json
mineru_output/招股说明书2/auto/招股说明书2.md
mineru_output/招股说明书2/auto/招股说明书2_content_list.json
```

### 2.3 启动 Redis 和 Milvus

Redis 用于短期对话和多模态缓存，Milvus 用于长期记忆和向量检索。

```powershell
docker compose up -d
```

默认地址：

```text
Redis  : localhost:6379
Milvus : localhost:19530
```

基础问答可以在外部服务不可用时降级运行，但短期记忆、长期记忆和向量检索能力会受影响。

## 4. 页面使用

### 4.1 配置面板

左侧配置面板会显示：

- 检索方式
- 索引名称
- 召回条数
- 当前知识库初始化状态
- 检索模式选择
- 回答语言选择

可点击：

- `重新解析并构建混合检索索引`
- `查看最近 20 条短期对话历史`
- `查看长期记忆`
- `运行工单问题评估`

### 4.2 检索模式

建议默认使用 `混合检索`。

- `混合检索`：BM25 + 向量 + RRF，适合大多数问题
- `BM25检索`：适合关键词非常明确的问题
- `向量检索`：适合语义表达较宽泛的问题

系统会对精确问题自动走快速路径，例如：

- 法定代表人
- 注册资本
- 技术标准
- 上游/下游
- 军用领域收入
- 收入比重
- 募集资金

### 4.4 查看调试信息

回答下方可展开调试信息，常见字段包括：

- 问题类型
- 检索模式
- 响应时间
- 置信度估算
- 命中片段数
- 查询分析
- 检索片段和分数

回答不符合预期时，优先查看命中的片段是否来自正确 PDF 和正确页。

## 5. 记忆功能

短期记忆：

- 依赖 Redis。
- 仅用于页面展示最近 20 条对话。
- 不参与回答生成。

长期记忆：

- 依赖 Milvus。
- 点击回答反馈中的 `有帮助` 后可保存优质问答。
- 当前默认不开启长期记忆自动回答，可通过配置开启。

## 6. 图片问题

系统保留多模态图片解析能力。对配置中的工单图片问题，系统会优先选择固定页面图片；如果图片不存在，会从 PDF 页面重新渲染。

相关配置在 `src/config.py`：

```python
MULTIMODAL_WORK_ORDER_IMAGES
MULTIMODAL_MODEL
ENABLE_MULTIMODAL_REDIS_CACHE
```

## 7. 工单问题评估

在页面点击 `运行工单问题评估`，或在命令行运行：

```powershell
.\.venv\Scripts\python.exe test_工单问题.py
```

结果包含每个问题的 RAG 答案、纯 LLM 答案、响应时间、检索模式、命中上下文数量和评分。

## 8. 常见问题

### 8.1 页面提示知识库未初始化

检查：

- `data/` 目录是否有 PDF
- PDF 是否可打开
- 依赖是否安装完整
- `logs/app.log` 是否有解析错误

然后点击 `重新解析并构建混合检索索引`。

### 8.2 Redis 不可用

```powershell
netstat -ano | Select-String ":6379"
.\.venv\Scripts\python.exe -m pip show redis
```

Redis 不可用时，短期记忆和多模态 Redis 缓存不可用，但基础问答仍可继续。

### 8.3 Milvus 不可用

```powershell
netstat -ano | Select-String ":19530"
.\.venv\Scripts\python.exe -m pip show pymilvus
```

Milvus 不可用时，长期记忆和向量检索不可用；精确问题仍可通过 BM25 和规则抽取回答。

### 8.4 回答跑偏

建议依次检查：

1. 展开调试信息，看命中片段是否正确。
2. 查看 `mineru_output/招股说明书*/auto/*.md` 和 `mineru_output/招股说明书*/auto/*content_list.json` 是否存在。
3. 查看 `mineru_output/*_chunks.json` 是否包含正确原文。
4. 检查问题是否应走固定元数据。
5. 检查 `src/retriever/query.py` 是否需要增加关键词加权。
6. 检查 `utils/llm_engine/local_answer.py` 或 `numeric.py` 是否需要增加规则抽取。

### 8.5 图片或表格解析不理想

查看：

```text
mineru_output/
```

复杂跨页表格或特殊图表可能需要人工复核。

## 10. 注意事项

- 不要删除 `data/` 中仍需问答的 PDF。
- 删除 `mineru_output/` 后需要重新运行 MinerU 解析。
- 当前默认要求 MinerU 生成 `.md` 和 `content_list.json`；缺少 `.md` 时会停止解析，不再生成本地降级结果。
- 精确问题优先走 BM25 快速路径。
- 外部 LLM 不可用时，系统会尽量使用本地规则和离线抽取兜底。
- 清理缓存文件不会影响功能，重新运行后会自动生成。
