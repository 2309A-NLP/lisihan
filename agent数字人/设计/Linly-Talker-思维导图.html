👤 用户输入

💡 三种交互模式：
① 直接回复 (无LLM): 文字 → TTS → Avatar
② 文字对话: 文字 → LLM → TTS → Avatar
③ 语音对话: 语音 → ASR → LLM → TTS → Avatar
④ MuseTalk实时模式: 语音 ↔ ASR ↔ LLM ↔ TTS ↔ 实时视频
